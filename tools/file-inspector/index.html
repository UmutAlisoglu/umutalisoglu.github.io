What stands out

    Byte entropy

    How random the bytes are across the file, from start to end. Text and tables are low; compressed or encrypted data is close to 8 bits per byte. A sudden change can mark a different embedded part.

    Checksums

    Compare checksums with the ones a download page publishes. Look up the SHA-256 on VirusTotal ↗ sends only the checksum, never the file, and only when you click.

    

      

      

      

      BEFORE YOU OPEN OR SHARE IT
      Look before you click.
      1. Check the real type
        The first bytes of a file say what it is. An “invoice.pdf” that is really a Windows program, or a “.jpg” that is a ZIP, is flagged straight away.
      2. See what it says about you
        Photos can hold GPS coordinates, camera serial numbers and an old thumbnail. Office files and PDFs keep author names, tracked changes, hidden sheets and edit history.
      3. Find what is tucked away
        Data appended after the end of an image, files inside files, macros, PDF scripts, user folder paths and invisible Unicode text show up as findings you can jump to in the hex view.
      What it does not do
      This is an inspector, not a virus scanner. It reads structures and signatures; it does not run, unpack or clean anything, and a file without findings is not guaranteed safe. Encrypted parts stay unreadable.
      Next steps
      To strip photo metadata, use Remove image metadata. To read a PDF’s text, use PDF → text.

      QUESTIONS
      A few answers.
      Is my file uploaded?
      No. The file is read inside your browser tab, in a background worker on your device. Nothing is sent to a server, and the result disappears when you clear it or close the tab.
      How does it know the real file type?
      Most formats start with a fixed byte pattern, often called magic bytes. PNG files start with 89 50 4E 47, PDFs with %PDF and ZIP-based files such as DOCX with PK. The inspector compares those bytes and the inner structure with more than 70 formats instead of trusting the extension.
      What metadata can it read?
      EXIF camera data and GPS locations in JPG, PNG, WebP, TIFF and HEIC, XMP edit history, PNG text chunks including AI image prompts, PDF document information, Word, Excel and PowerPoint properties, audio tags, video creation dates and locations, and details of Windows, Linux and macOS programs.
      What counts as hidden data?
      Bytes after the official end of a file, other files embedded inside it, tracked changes and hidden text or sheets in Office files, PDF scripts and earlier PDF versions kept by incremental saves, private keys and tokens, user folder paths and invisible Unicode characters.
      Can it tell me if a file is safe?
      It can point out red flags such as disguised programs, macros or PDF JavaScript, but it is not an antivirus. When in doubt, do not open the file, and check its SHA-256 checksum with a scanner you trust.
      

      Your files stay with you.
      No upload, account or saved history. The inspector only reads the file you choose; clearing it releases it from memory.
