THREE SMALL STEPS

Here’s how it works.

  1. Choose a PDF

    One unlocked PDF up to 25 MB and 200 pages. The original stays unchanged.

  2. Type the pages

    Use page numbers and ranges such as 1, 3-5, 9. Leave the field blank to keep every page.

  3. Extract & download

    The selected pages become one new PDF. For a second file, change the range and export again.

Before you start

Pages keep their order in the document, and duplicates appear only once. Forms and signed PDFs are refused. Bookmarks and interactive features may not be kept.

GOOD TO KNOW

A few answers.

Are my files uploaded?

No. The file is read and processed in this browser tab. Nothing is sent to a server, and the result disappears when you close the page, so download it first.

Can I get one file per page?

Each export creates one PDF. Run it once per range you need, for example 1, then 2, then 3-4.

Is the text still selectable?

Yes. Pages are copied as they are, including text, links and images.

Why is my signed PDF refused?

Copying pages into a new file would invalidate the signature. Ask the sender for an unsigned copy if you need only part of it.

Your files stay with you.

No upload, account or saved conversion history. Download your result before leaving the page.
