FROM TYPO TO FIXED

Three clicks, no upload.

  1. Open your PDF

    Drop a PDF with real, selectable text. The page appears as it looks in a PDF reader, with every line you can change outlined when you hover over it.

  2. Click a line and type

    The tool picks the closest font, size and colour for you and matches the page background. Change any of them, or use Add text to place a new line anywhere.

  3. Download the result

    Everything else on the page stays untouched. Tick “Remove the original text completely” if the old words must not survive in the file.

What it does not do

A PDF stores glyphs at positions, not paragraphs, so you edit one line at a time and the new text uses a standard font, not the original one. Scanned pages need Extract text first. Signed PDFs lose their signature when edited, and form fields are not changed.

Next steps

To pull out every word instead, use PDF → text. To rearrange pages, use the PDF organizer.

QUESTIONS

A few answers.

Is my PDF uploaded?

No. The file is opened and rewritten inside your browser tab. Nothing is sent to a server, and the edits disappear when you clear the file or close the tab.

Can I really edit the text in any PDF?

In any PDF that contains real text. Scanned pages are only pictures of text and have nothing to click. The tool covers the old line with a patch in the page colour and draws the new line on top. That works well for names, dates, amounts and typos. It is not a full layout editor, so long rewrites that need re-flowing a paragraph are better made in the original Word or design file.

Is the old text really gone?

By default it is only covered. It still sits underneath the patch and a text extractor can find it. If you are removing a name, a number or anything private, tick “Remove the original text completely”. The edited pages are then saved as pictures with your new text on top, and the original words are not in the file any more.

Why does the new text look slightly different?

The original font is often a subset embedded in the file and cannot be reused for new letters. The tool picks the nearest standard font (Helvetica, Times or Courier) and the same size and colour. For characters such as Turkish, Cyrillic or Greek letters it switches to Noto Sans automatically. Chinese, Japanese, Korean and emoji are not covered.

What happens to signatures, forms and links?

A digital signature is broken by any change, which is correct. Form fields and links stay in the file if you do not flatten, but they are not editable here. Flattened pages lose their links and form fields.

Your files stay with you.

No upload, account or saved history. The PDF is read and rewritten in this tab; clearing it releases it from memory.
