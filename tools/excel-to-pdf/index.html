THREE SMALL STEPS

Here’s how it works.

  1. Choose an XLSX or CSV

    Select one workbook or a UTF-8 CSV file. Visible sheets are included; hidden sheets are skipped.

  2. Choose the layout

    Use landscape for wide tables or portrait for narrower lists. Large sheets split across pages and column groups.

  3. Create your PDF

    Download the table export and check it. The first row repeats as a heading on each page.

✳

Before you start

One file, up to 10 MB. Up to 10,000 rows and 80 columns per visible sheet, 20,000 rows total, and 1,500 PDF pages. Charts, images, merged cells and the original Excel print layout are not preserved.

Try it for…

Turn an equipment inventory into a PDF for sharing. Put column names in row one, save the workbook, and choose landscape if there are several columns.

GOOD TO KNOW

A few answers.

Will it look exactly like printing from Excel?

No. This creates a fresh table layout from visible sheet data. If you need Excel’s exact formatting, charts or print areas, export to PDF from Excel itself.

Are formulas calculated?

The tool uses saved formula results when present. It does not recalculate a workbook. Missing results appear as formula text, with a warning. Recalculate and save in your spreadsheet app first.

Can I use an older .xls file?

The browser tool accepts .xlsx and UTF-8 .csv. Save your older workbook in one of those formats first.

Your files stay with you.

Selected files are processed in your browser. No upload, account or saved conversion history. Download your result before leaving the page.
