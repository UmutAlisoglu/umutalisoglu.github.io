GOOD TO KNOW

A few answers.

Are my files uploaded or stored?

No. Processing happens in your browser. Files, pasted text and results stay in this tab’s memory. Download the result before leaving. The host receives ordinary page requests, not your selected file contents.

Does “local” mean no internet requests?

The browser downloads this page and its code from this website. Selected files and pasted text aren’t uploaded. Optional offline mode saves public tool code; it doesn’t save your files or results.
