THREE SMALL STEPS

Here’s how it works.

  1. Paste or open your data

    Paste text or open one UTF-8 CSV or JSON file up to 2 MB, 10,000 rows and 100 columns.

  2. Pick the direction

    CSV → JSON turns each row into an object. JSON → CSV needs an array of flat objects.

  3. Copy or download

    Check the result, copy it to the clipboard or download it as a file.

Before you start

CSV needs a header row and comma separators. Values stay text; numbers are not guessed. Nested JSON objects and arrays need to be flattened first.

Formula protection

Cells starting with =, +, - or @ can run as formulas when a CSV opens in a spreadsheet app. For JSON → CSV, protection is on by default and adds a leading apostrophe.

GOOD TO KNOW

A few answers.

Are my files uploaded or stored?

No. Processing happens in your browser. Files, pasted text and results stay in this tab’s memory. Download the result before leaving. The host receives ordinary page requests, not your selected file contents.

Does “local” mean no internet requests?

The browser downloads this page and its code from this website. Selected files and pasted text aren’t uploaded. Optional offline mode saves public tool code; it doesn’t save your files or results.

Your files stay with you.

Free to use. No upload, account or saved conversion history. Download your result before leaving.
