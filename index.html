02 / THE PROCESS

A problem first.
Then a prompt.

AI is part of how these projects get built.
I’d rather say that clearly.

01

Notice the friction.

A file is too big. A GitHub project takes too many steps to try. Start with something worth making easier.

02

Let AI build.

Describe the idea, choose the direction, and use AI to turn it into a first working version.

03

Refine the result.

Use feedback and checks to improve it. Share the useful parts, along with clear notes about the current limits.
