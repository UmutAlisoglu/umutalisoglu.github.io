    SHARE THE GUIDE, KEEP THE EDITOR

    One file.
    Ready to follow.

    The shared guide is a self-contained HTML file. Readers choose an answer to move between steps, using native links and CSS. No scripts, account, installation, or connection are needed to follow it. Use the browser’s Back button to revisit a choice.

    Save project creates a separate JSON file for future editing. Only connected steps appear in the shared guide; the project JSON includes every step. Check the preview and route warnings before sending it.

    Routeboard uses this tab’s memory and saves no project history, cookies, or local storage. Ordinary hosting requests load the online app. The portable download works offline.

    Formats & limits

    Up to 80 steps and 8 choices per step. Plain-text instructions; no embedded code, uploads, or external media. Guide title and step titles: 120 characters. Instructions: 6,000 characters per step. Project JSON: up to 2 MB. A modern browser with CSS :has support is required for the best guide experience. Printed guides show all connected steps. Project files and exported guides contain the text you include; share them with the intended readers.
