Export packet creates a self-contained HTML document with your text and embedded screenshots. It opens offline with no scripts. Readers can follow external links if they choose. Use Print to save it as a PDF.

Save project creates JSON for later editing. Markdown gives you a text version for a README or notes app; screenshots stay in the HTML packet and JSON. The packet is a snapshot, not a shared task tracker.

Handback uses this page’s memory. There are no uploads, accounts, analytics, or saved history. Ordinary hosting requests load the online app; the portable download works offline. Packets contain the details and images you include, so review them before sharing.

Formats, screenshots & limits

Save and open Handback project JSON, up to 25 MB. Up to 100 tasks, 30 notes, 50 decisions, 50 questions and 60 links. Only complete http:// and https:// links without embedded credentials are accepted for export.

Add up to 8 PNG, JPEG or WebP screenshots, 5 MB per source image. Screenshots are decoded and re-encoded locally, resized to at most 1,600 pixels on the longest edge, and stored without the original file metadata. Processed images are limited to 2 MB each and 8 MB total. Animated images are not preserved. SVG, PDF and other attachments are not supported; use a link to those resources instead. The exported HTML and project JSON embed your screenshots; Markdown lists captions only.
