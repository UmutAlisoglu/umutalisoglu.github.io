# FileForge samples

The headphones image is synthetic sample artwork for trying background removal. It isn’t a real product, a customer photo or an endorsement. The cutout you download is processed locally by FileForge and includes your own edits.

The text and PDF samples are created in the browser by `src/site/workspace-samples.js` using original example content. Screenshot studio and Document scanner have their own locally drawn samples.
# Product demonstration recording

`fileforge-attachment.webm` is a silent recording of an actual local FileForge
attachment workflow using the original `headphones.png` sample. Its poster is
`attachment-poster.png`. `scripts/record-attachment-demo.mjs` regenerates both.
The product page provides a written transcript, and neither video playback nor
offline caching is automatic. The video uses no visitor files.
