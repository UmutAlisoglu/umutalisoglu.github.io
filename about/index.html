HELLO AGAIN

I’m Umut.
I make stuff.

Mostly software. Tools for files, apps for the desktop, and sometimes a game. This website gives those projects somewhere to live.

A lot of them start with a small annoyance. Converting a file shouldn’t mean sending it to a random website. Running a project shouldn’t mean hunting through terminal windows. And sometimes, I just want to see if an idea could be fun.

I like things that are easy to pick up and don’t get in the way. That’s what I’m aiming for here, too.
