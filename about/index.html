THE PERSON BEHIND THE PROJECTS

Hi, I’m Umut.

I’m the person behind Rowglass, FileForge and Repodock. My projects focus on practical tasks: working with everyday files and making local software easier to manage.

Rowglass compares two table exports and turns the differences into a clear report. FileForge brings file conversion and PDF tools into the browser. Repodock gives GitHub projects a dashboard on Windows, with run controls and logs in one place.

The browser tools run on your device, without an account or file upload. The desktop apps have public source and downloads. This site keeps the projects together, with enough detail to get started.
