A LITTLE LESS BACK-AND-FORTH

A process
you can follow.

Some instructions need a different next step depending on the answer. Routeboard lets you write those branches, connect them, and try the result in a live walkthrough.

  • Write steps with plain-text instructions and up to eight choices each.
  • Use the step list and route overview to see where each choice leads.
  • Choose the starting step, then test your route with Back and Restart.
  • Missing destinations and empty connected titles or choice labels block export.
  • Loops are allowed with a warning. Unconnected drafts stay out of the shared guide.

KEEP IT. SHARE IT.

One HTML file.
No scripts needed.

Export guide creates a self-contained HTML file. Readers follow ordinary links between steps and use the browser’s Back button to revisit a choice. No scripts, account or connection are needed. Printing shows every connected step; use Print to save a PDF.

Save project downloads a separate JSON file for future editing. The project includes every step, including drafts. The shared HTML includes only steps connected to the starting point. Three fictional examples are included.

Exported files contain the content you include. Read the result before sharing it with the intended recipients.

Release notes & checksum ↗

Formats & practical limits

Up to 80 steps, 8 choices per step, and 6,000 characters of plain-text instructions per step. Project JSON up to 2 MB. No embedded media, HTML or code. Use a modern browser with CSS :has support for the best guide experience.

Your working copy stays in page memory. Save project before closing the tab, then reopen the JSON when you want to continue.

LOCAL BY DESIGN

Keep your work
in your hands.

The editor makes no upload, analytics or account requests and saves no project history to cookies, localStorage or IndexedDB. Saved downloads remain where you save them.

The online app loads its public code from GitHub Pages, which receives ordinary connection information. The portable download works with the network disconnected. Exported HTML can be read without JavaScript.
