THE IDEA

Why this project exists

Repodock helps with the space between discovering a repository and actually running it. Paste a GitHub repository or username, download a project and review the detected commands before starting.

A design choice: visible controls

The dashboard brings together start/stop controls, live logs, resource use, ports and project settings. Each project still needs its own dependencies and runtime, such as Node.js or Python.

▷

v0.2.1 release notes ↗

  1. Install or extract

    Run the Windows installer, or extract the portable ZIP. The app uses Microsoft Edge WebView2. No separate Python installation is needed for the packaged app.

  2. Add a project

    Paste a GitHub link. Review setup and run commands, then install the runtime that the project requires.

  3. Run from the dashboard

    Use the project controls and inspect its output. Closing the window leaves apps running in the tray; choose Quit from the tray to stop them.

WHAT THIS PROJECT EXPLORES

Making local software
easier to manage.

Repodock brings project discovery, command detection and process controls into a desktop interface. It supports common project types, but unusual repositories may still need manual setup.

It is a Windows desktop download, not a browser tool. The repository also documents running from Python on macOS and Linux.
