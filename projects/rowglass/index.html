WHY I MADE IT

Another export.
A useful answer.

A table can look completely different just because someone sorted it. Rowglass follows the records using a stable value, such as an ID, SKU, email or part reference, so you can focus on the changes.

There’s a matching-column suggestion to get started, and a second column when a single value isn’t unique. Duplicate or empty matching values are flagged instead of being paired at random.

A REPORT YOU CAN KEEP

The details.
And the bigger picture.

Start with a change brief and totals, then filter, search, and inspect individual records. Exact text matching is the default. Optional rules let you ignore edge spaces, letter case or columns, and compare decimal values with an absolute tolerance.

Save a readable HTML report with every changed, added and removed row. It opens offline with no scripts or external resources. Use your browser’s Print menu to save it as a PDF. CSV and full JSON exports are available too.

Reports include your table data. Share them only with their intended recipients. Formula-like values in CSV exports are prefixed with an apostrophe; use JSON when exact source strings matter.

Formats & practical limits

CSV, TSV and delimited text, with comma, tab, semicolon or pipe separators. UTF-8 and BOM-marked UTF-16. Up to 10 MB, 20,000 data rows, 200 columns and 1,000,000 cells per table.

Export XLSX sheets to CSV first. Each table needs a header row with unique column names and a consistent number of cells. Rowglass compares exported values, not workbook formulas or formatting.

Column names must match exactly after trimming header-edge spaces. If an identifier changes, the old row is removed and the new one added. Matching is explicit; there’s no fuzzy identity guess.

LOCAL BY DESIGN

Your tables
stay yours.

Files and results stay in this page’s memory. Rowglass makes no upload or analytics requests and saves no input, filename or comparison history. Clear everything or close the page to release the session. Downloads remain wherever you save them.

The online app is hosted on GitHub Pages, which receives ordinary connection information when serving the app. The portable version can be used with your network disconnected.
