A LITTLE LESS BACK-AND-FORTH

Leave the next
person some context.

Finishing your part is easier when the next person can see where things stand. Handback keeps the short version, the reasons behind decisions, and the outstanding work together.

  • Write a summary and name who is handing over to whom.
  • Add next steps with optional owners, dates and already-done status.
  • Keep deeper notes, decisions and open questions in separate sections.
  • Add complete HTTP or HTTPS links to the useful resources.
  • Include up to eight screenshots, resized and re-encoded locally.

KEEP IT. SHARE IT.

A packet that
stays together.

Export packet creates a self-contained HTML document with embedded screenshots and no scripts. It is a snapshot, not a live shared task board. External links open only when selected. Use Print to save a PDF.

Save project downloads JSON for later editing. Markdown creates a text version for a README or notes app; screenshots remain in the HTML and JSON. Three fictional examples cover a website project, workshop build and event handover.

Exported files contain the content you include. Read the result before sharing it with the intended recipients.

Release notes & checksum ↗

Formats & practical limits

Project JSON up to 25 MB. Up to 100 tasks, 30 notes, 50 decisions, 50 questions and 60 links. Up to eight PNG, JPEG or WebP screenshots, 5 MB per source image. Images resize to a maximum edge of 1,600 pixels and flatten onto white as JPEG. Processed image limits: 2 MB each, 8 MB total. Other attachments are linked rather than embedded.

Your working copy stays in page memory. Save project before closing the tab, then reopen the JSON when you want to continue.

LOCAL BY DESIGN

Keep your work
in your hands.

The editor makes no upload, analytics or account requests and saves no project history to cookies, localStorage or IndexedDB. Saved downloads remain where you save them.

The online app loads its public code from GitHub Pages, which receives ordinary connection information. The portable download works with the network disconnected. Exported HTML can be read without JavaScript.
