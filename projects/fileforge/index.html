THE IDEA

Less uploading.
More doing.

FileForge brings common conversions into one place. The browser version reads the files you select, does the processing locally, and gives you a download.

Image processing and document work run in background browser tasks. Video compression uses FFmpeg compiled for the browser. The larger engine only loads when you start a video job.

All releases & notes ↗

  1. Extract the ZIP

    Keep the extracted files together. Run install.cmd for a per-user installation, or launch FileForge.exe.

  2. Check the requirements

    Microsoft Edge WebView2 is required. For video compression, install FFmpeg and FFprobe and make them available on PATH; they are not bundled.

  3. Start a job

    Choose a tool and a file. The desktop app has its own size limits and local temporary-file behaviour, documented in its README.
