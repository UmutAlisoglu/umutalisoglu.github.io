THE IDEA

Everyday file work,
in one place.

Why this project exists

FileForge brings common conversions into one place. The browser version reads the files you select, does the processing locally, and gives you a download.

A design choice: local processing

Image processing and document work run in background browser tasks. Video compression uses FFmpeg compiled for the browser. The larger engine only loads when you start a video job.

All releases & notes ↗

  1. Extract the ZIP

    Keep the workspace folder beside FileForge.exe. Run install.cmd to install both for your Windows user, or launch the executable from the extracted folder. Close FileForge before updating.

  2. Check the requirements

    Microsoft Edge WebView2 is required. Workspace engines are bundled. Only the native video tool needs separately installed FFmpeg and FFprobe on PATH.

  3. Start a job

    Use the connected workspace for 22 tasks, or switch to Native tools for the existing nine converters and larger file limits. Models, fonts and OCR languages are bundled. Save workspace results before leaving; native jobs use temporary copies on this computer.

BEFORE YOU EXPORT

Know what
you’re getting.

Office → PDF: DOCX and PPTX exports are page images. Fonts and page breaks can differ from Microsoft Office; review every page. Use Office’s own export when exact layout or selectable text is essential.

OCR and compression: OCR makes editable TXT, not a searchable PDF. PDF compression targets supported JPEG images and may not shrink an already optimized document.

Image cutouts: Automatic background removal can need edge cleanup. Use the erase and restore controls to refine the result before exporting.
