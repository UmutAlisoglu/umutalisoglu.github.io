Location and camera metadata

Image exports made by the image tools are newly encoded without the source photo’s EXIF or GPS data. The metadata cleaner removes descriptive tags from JPG and PNG without recompressing the pixels; it keeps colour profiles and only the orientation tag when needed. Keep your original separately if you need its camera data. These tools do not hide faces, addresses or anything visible in the picture. PDF compression and splitting are not metadata cleaners and may retain document metadata and attachments.

What happens to selected files?

FileForge reads the files you select into browser memory and processes them on your device. The website has no file-upload endpoint, online file storage or account system. The connected workspace keeps only the current session’s task names and sizes in memory; it does not save conversion history. Your source files are not changed. Passing a result between tools uses a same-origin message containing a temporary File object; the data stays in browser memory.

You choose whether to download the result. Clearing a selection releases the tool’s references, previews and result link. Leaving or closing the page ends its current work. Your browser and operating system manage memory cleanup; this is not a promise of secure memory erasure.

Your browser may cache website code, fonts, conversion engines and the public background-removal model. Background removal downloads its model/runtime from this website when you start a job; no image is sent to the model publisher or used for training. Search filters tool names locally and does not send your search text to a service. FileForge does not use that cache to save your selected files or results. Text extraction downloads its engine and your chosen English, German or Turkish language pack from this website. Images and rendered PDF pages are recognized locally; OCR text is temporary until you copy or download it. Screenshot studio and Document scanner draw and correct images on your device. Their samples are generated locally. Pasting a clipboard file selects it only when you explicitly paste outside a text field; the tools do not read your clipboard in the background.

What can be saved on this device?

The Image studio has an optional “Remember my image settings” checkbox. If selected, it stores only output format, quality, maximum width and a settings version in your browser’s local storage, under fileforge:image-settings:v1.

The workspace also offers an optional “Remember my favourite tools” checkbox. It saves only tool identifiers and a preferences version under fileforge:favourite-tools:v1. Uncheck it to remove those preferences.

Offline mode is optional. Choosing “Save selected tools offline” stores public website pages, code, engines and model/language packs in Cache Storage. Small cache records contain build versions and temporary browser-client identifiers to keep open tools on compatible versions. They contain no selected files, results, filenames or OCR text. “Clear offline tools” removes FileForge’s offline caches and worker; it does not clear Skate Scape saves or other site storage. Browsers may evict cached resources.

No filenames or file contents are included. Uncheck the option in Image studio to remove those settings, or clear this site’s data in your browser. The website does not set analytics or advertising cookies.

The idea machine and feedback form keep what you type in the current page only. Feedback leaves the site only when you choose to continue to GitHub.

Skate Scape uses local game storage

Skate Scape is a separate project served at /skate-scape/. Its first run downloads game data from the 2009scape project on GitLab and builds the world in the browser. Those requests go to an external service, which receives ordinary request information such as your IP address.

The game keeps downloaded and built game data in IndexedDB and stores progress and preferences in local browser storage. Clearing this site’s browser data can remove game saves as well as the cache and FileForge settings.

See the game’s current documentation for its loading and storage behaviour. The FileForge no-upload promise concerns the files you select in FileForge; it does not mean that the game makes no network requests.

What about ordinary website visits?

GitHub Pages hosts this website. Loading a page sends ordinary network requests to the host, including your IP address. GitHub states that it logs visitor IP addresses for security purposes. This is separate from the contents of files you select inside FileForge.

Cloudflare provides the domain and DNS service. DNS is the lookup that helps a browser find the website; it is not where FileForge conversions run.

Read GitHub Pages’ data collection note, the GitHub privacy statement and Cloudflare’s privacy policy for those services’ own practices.

Links, downloads and feedback

Source code, desktop downloads and issue reporting link to GitHub. Opening those links uses GitHub’s service under its own policies. Submitting an issue in a public repository makes that report public; don’t include private documents, passwords or personal information.

The contact page can prepare an issue draft locally. It does not submit or publish anything for you. You review and submit on GitHub.

This page describes the website and browser tools. Desktop apps have their own behaviour, including local working files. See the FileForge desktop documentation and Repodock documentation before installing.
